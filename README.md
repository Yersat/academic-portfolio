# Academic Portfolio & CMS

Personal academic website for Sabina Ayazbekova with a book catalog, articles, videos and an admin panel. Live at https://ayazbekova.kz.

Books are bought through WhatsApp: the button on a book page opens a chat with a prefilled message, and payment is arranged there.

## Tech Stack

- React 19, TypeScript, Vite, React Router, Tailwind CSS (CDN)
- Convex (database, backend functions, file storage)
- Netlify (hosting; builds automatically from the `main` branch)

## Commands

```bash
npm install
npm run dev    # Convex dev server + Vite frontend
npm run build  # Production build of the frontend
```

See `CLAUDE.md` for project structure and conventions.
